## Known Limitations

- The local HRP file has no explicit status field, so active status is inferred from dates and labelled `medium_date_inferred`.
- No formal INFORM, IPC, or IDP severity data is included in the generated outputs.
- Food-insecurity queries use food-sector HNO/FTS proxy logic, not IPC phase data.
- CBPF country mapping uses aliases and should be replaced by an authoritative CBPF country dimension for production.
- HNO sector PIN values can overlap, so sector PIN is never summed across sectors.
- The score is for triage and review, not final funding allocation.
